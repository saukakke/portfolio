# Yasin Muhammed Tukur — Portfolio

Personal portfolio website for Yasin Muhammed Tukur, software engineer, EdTech builder and full-stack Laravel developer.

## Stack

- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages

## Design direction

Built around a premium dark product-portfolio aesthetic: deep navy surfaces, electric blue accents, glass cards, bento-style project presentation, strong typographic hierarchy, responsive layouts, subtle motion and accessible focus states.

The design direction follows the UI/UX Pro Max methodology and its recommendations for portfolio interfaces, typography, hierarchy, responsive behavior and UX quality.

## Deployment

The site is deployed through the GitHub Pages Actions workflow in `.github/workflows/pages.yml`.

Expected URL:

`https://saukakke.github.io/portfolio/`
